# LeetCode Swift

Working through LeetCode problems in Swift. Mostly doing this to get 
comfortable with algorithms and idiomatic Swift at the same time.

Each solution lives in its own file, namespaced inside a caseless enum 
so nothing collides. Tests are written with Swift Testing and cover the 
examples from each problem's LeetCode page.

Swift package, no Xcode project file. Run the tests with:

    swift test
